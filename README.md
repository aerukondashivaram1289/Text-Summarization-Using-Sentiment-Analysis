# Text Summarization using Sentiment Analysis

## Overview

This project combines Text Summarization and Sentiment Analysis using Natural Language Processing (NLP). The system generates concise summaries from lengthy text documents and identifies the sentiment expressed in the text as Positive, Negative, or Neutral.

## Features

* Automatic text summarization
* Sentiment classification
* NLP-based text preprocessing
* Easy-to-use Python implementation
* Supports large text inputs

## Technologies Used

* Python
* NLTK
* TensorFlow / Keras
* Transformers
* NumPy
* Pandas

## Project Workflow

1. Input text is provided by the user.
2. Text preprocessing is performed.
3. Important sentences are extracted for summarization.
4. Sentiment analysis is applied to the text.
5. Summary and sentiment results are displayed.

## Applications

* News article summarization
* Social media analysis
* Customer review analysis
* Research document summarization
* Opinion mining

## Future Enhancements

* Support for multiple languages
* Real-time text analysis
* Improved deep learning models
